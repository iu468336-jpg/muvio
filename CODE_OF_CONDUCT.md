# Code de Conduite (Contributor Covenant)

## Notre engagement

Nous nous engageons à faire de la communauté **Muvio** un espace ouvert, accueillant, respectueux et inclusif pour toutes et tous, quel que soit le niveau d'expérience, l'origine ou la langue.

## Comportements encouragés

- Utiliser un langage bienveillant et constructif lors des revues de code et discussions techniques.
- Respecter les choix techniques documentés dans `docs/ARCHITECTURE.md` et `docs/DESIGN.md`.
- Accepter les retours critiques avec ouverture d'esprit.

## Comportements inacceptables

- Harcèlement, insultes ou attaques personnelles.
- Publication ou partage de liens pointant directement vers des contenus piratés dans les issues ou pull requests (Muvio est strictement un lecteur et agrégateur technique neutre).

## Application

Les mainteneurs du projet se réservent le droit de modérer, éditer ou fermer toute contribution ne respectant pas ce Code de Conduite ou la législation applicable.
